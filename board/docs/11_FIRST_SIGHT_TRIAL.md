# 11 — First-Sight Trial

**Status:** Ready for human acceptance
**Purpose:** Five-minute usability check for the NOT-gate Board.

---

## Participants

Run separately with:
- One learner aged 13-15
- One adult beginner (no electronics background)

Do not teach Component vocabulary or demo the Board first.
Ask participant to think aloud; record where help was needed.

## Setup

1. Start Board with command in `board/README.md`
2. Fresh browser profile or clear local draft/profile keys
3. Keep checklist with observer, not on learner screen

## Five-Minute Route

| Check | Prompt | Pass |
|-------|--------|------|
| Understand | "What does this machine do?" | Explains NOT in own words |
| Locate | "Show me input and output" | Points to IN and OUT |
| Try | "What can you safely try?" | Uses Try inversion, describes result |
| Change | "Make one connection change, check first" | Sees preview, can Apply or Cancel |
| Recover | Ask for invalid connection | Reads explanation, source unchanged |
| Cancel | Start connection, press Escape | Preview disappears, nothing changed |
| Keyboard | Tab to pins, Enter/Space to connect | Same preview/apply without pointer |

## Record

```
Participant: learner 13-15 | adult beginner
Completed without guide: yes | no
If no, first blocked check:
One confusing label/step:
Suggested change:
Observer/date:
```

## Gate

Board passes only when BOTH participants complete without a guide.
If either needs help: revise wording/screen, repeat trial.
Do not add Working Box, BOM, bus routing, or advanced features until passed.
